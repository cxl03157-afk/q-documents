## 補足：ファイルアップロード後の非同期処理

実ファイルは署名付きURLでS3へ直接PUTする（API Gatewayは経由しない）。
PUT完了をS3イベントで検知し、非同期Lambdaが以下を実行する。
クライアントから呼び出すエンドポイントは持たない。

1. ファイル名から文書番号と拡張子を解析し、S3キー(PDF)またはS3キー(Excel)を台帳に記録する
2. PDF・Excelの両方が揃った場合、状態を「最新」に更新する
  （同時アップロード時の二重実行を防ぐため、条件付き書き込みで先勝ちとする）
3. 最新版のExcelをStandard-IAへ移行する
4. 同一文書IDの前リビジョンを「旧版」に更新し、両ファイルをGlacier IRへ移行する

対応機能：F-04（自動アーカイブ）、F-07（台帳への保管）

## 補足：合言葉による制御について

**合言葉トークンを要求する範囲**

| 対象 | 要否 | 理由 |
| --- | --- | --- |
| 書き込み系すべて（登録・修正・削除・リビジョンアップ・マスタ編集・アップロード） | **要** | いずれも生産技術だけが行う操作。合言葉がないと誰でも台帳を削除・改ざんできる |
| エクセル・旧版のファイル取得 | **要** | エクセルは原本であり、旧版は誤使用の原因になる |
| 最新版PDFのファイル取得 | 不要 | 全利用者が閲覧してよい |
| 読み取り専用のGET（一覧・マスタ取得・番号プレビュー） | 不要 | 台帳のメタデータは社内利用者に隠す必要がない |

**検証はサーバー側で行う。** 画面側だけの制御では開発者ツールから回避できるため、
Lambda が SSM Parameter Store から読み出した合言葉と照合してからトークンを発行し、
以降のリクエストではトークンを検証する。

**一覧の「表示」は画面側で行う。**
`GET /documents` は旧版を含む全件を返す。**論理削除は既定で除外**するが、
合言葉トークンを添えた場合のみ削除済みも含めて返す（文書管理者が何を消したかを追えるようにするため）。
削除済みのファイル取得はエクセルに限る（PDFは配布物のため、消した版を現場に出さない）。

どの行をどう見せるかは画面側が判断する。

**合言葉は個人を認証するものではない。**
役割単位（生産技術）で共有する1つの値であり、氏名は自己申告である。
記録は本人性の証明ではなく抑止力として機能する（要件定義書 §4.3）。

## 補足：upload-url のファイル名検証

`POST /documents/{docNo}/upload-url` は PDF・エクセル両方のファイル名を受け取り、
**署名付きURLを発行する前に**以下を検証する。1つでも満たさなければURLを発行しない。

1. PDF側のファイル名が `.pdf` で終わること
2. エクセル側のファイル名が `.xlsx` で終わること
3. 2つのファイル名の文書番号部分が一致すること
4. 文書番号がパスの `{docNo}` と一致すること
5. 文書番号が命名ルールの形式に従うこと（`../` や `/` を含まないこと）
6. 台帳照合（F-01）：未登録番号・旧版リビジョン・同一種別が登録済み のいずれでもないこと

画面側でも同じ検証を行うが、**サーバー側の検証を正とする**。
画面側だけの検証では、開発者ツールから直接APIを呼ばれた場合に壊れたデータが登録されてしまう。

具体的には、エクセル欄にPDFを選んだまま通過すると、S3の `.xlsx` キーにPDFの実体が保存され、
非同期Lambdaは「両方揃った」と判断して状態を「最新」にする。
台帳上は正常に見えるため、後日エクセルを開くまで誤りに気づけない。

発行する署名付きURLには `Content-Type` を署名条件に含める。
エクセル用URLにPDFを送信した場合、S3側でも拒否される。

## 補足：セキュリティ

- APIは社内ネットワークのグローバルIPからのみ受け付ける(API Gateway REST APIのリソースポリシー)
- CORSは自サイトのオリジンのみ許可し、ワイルドカードは使用しない
- 署名付きURLの有効期限は15分以内とする
- アップロード用の署名付きURLには content-length-range を含め、ファイルサイズ上限を強制する
- ファイル名の検証は「補足：upload-url のファイル名検証」を参照（パストラバーサル対策を含む）
- 合言葉は SSM Parameter Store（SecureString）から読み込み、コードやTerraform stateに平文で残さない
- 合言葉トークンはブラウザのタブを閉じるまで有効（sessionStorage 保持）とし、サーバー側でも有効期限を設ける
- エクセル・旧版のURL発行時は、氏名・文書番号・ファイル種別・日時をCloudWatch Logsに記録する

対応機能：5.1 セキュリティ要件
